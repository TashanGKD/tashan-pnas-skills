# PNAS Writing

Use this skill to turn research material into a PNAS-style manuscript argument. Focus on significance, evidence, scope, and reader path before sentence polish.

## Intake

Before drafting, identify:

- Target section: Significance Statement, Abstract, Introduction, Results, Discussion, Methods, SI, title, or full outline.
- Paper type: mechanism, theory, simulation, method, resource, experiment, or interdisciplinary synthesis.
- Core claim: what the work actually demonstrates.
- Evidence: figures, equations, simulations, parameter scans, controls, literature, or data.
- Boundary: where the claim stops.
- Reader: broad scientific PNAS audience plus domain reviewers.

If claim, evidence, or boundary is missing, expose the gap before drafting. You may provide a scaffold with explicit placeholders.

## Workflow

1. Write the manuscript argument in one sentence: `In [system/problem], we show [advance] using [approach], supported by [evidence], within [boundary].`
2. Choose the section architecture. Use `references/section-architecture.md`.
3. Build a claim-evidence map before prose.
4. Draft from evidence outward. Keep claims near the data or derivation that supports them.
5. Calibrate verbs using claim strength: demonstrate, show, indicate, suggest, are consistent with, may.
6. Add PNAS-style significance bridges for non-specialist scientists.
7. Run a reviewer-risk audit. Use `references/reviewer-risk.md`.

For theory-simulation, RDME, landscape/flux, stochastic polarity, or mechanobiology manuscripts, also use `references/evidence-backed-writing-rules.md`. For SI, Methods, parameter, derivation, reproducibility, or caption-support questions, use `references/si-parameter-evidence.md`.

## PNAS Priorities

- Make the broader scientific problem visible without inflating the claim.
- Keep specialized terms explainable on first use.
- Use Significance Statement to explain why the work matters, not to repeat the abstract.
- Use Results as an evidence ladder, not a chronological lab diary.
- Keep Discussion focused on mechanism, boundary, relation to prior work, and predictions.
- For simulation or theory work, make assumptions, parameter regimes, and model-to-biology translation explicit.

## Output

Default output:

1. Draft or revised text.
2. Claim-evidence map.
3. Structural notes.
4. Unsupported or overstrong claims.
5. Missing inputs or citations.
6. Next revision action.
