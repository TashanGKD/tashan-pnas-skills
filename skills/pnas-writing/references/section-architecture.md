# PNAS Section Architecture

## Significance Statement

Use:

`broad problem -> unresolved gap -> what this work shows -> why it matters beyond the narrow system`

Rules:

- Write for scientists outside the immediate subfield.
- Avoid method-heavy detail unless the method is the contribution.
- Avoid repeating the abstract sentence by sentence.
- Prefer conceptual significance, predictive value, reusable framework, or mechanism.
- Avoid unsupported claims such as "universal", "paradigm-shifting", or "first" unless verified.

## Abstract

Use:

`context -> gap -> approach -> key finding -> implication -> boundary`

For theory-simulation papers, include model class and evidence type:

- stochastic simulation
- analytical reduction
- parameter scan
- continuum or master-equation model
- comparison to prior model or experimental regime

## Introduction

Use an hourglass:

1. Broad biological or physical problem.
2. What is known.
3. What remains unresolved.
4. Why previous approaches are insufficient.
5. Current approach.
6. Main advance and scope.

Group prior work by mechanism or limitation, not publication chronology.

## Results

Use an evidence ladder:

1. Define model or system only as needed.
2. Validate against known behavior or limiting case.
3. Present main result.
4. Diagnose mechanism.
5. Test robustness across parameter regimes.
6. Connect to biological or physical interpretation.

Each subsection should open with a testable claim.

## Discussion

Use:

`central advance -> mechanism -> relation to prior work -> limitations -> predictions or future tests`

Do not repeat all results. State the boundary of model assumptions clearly.
